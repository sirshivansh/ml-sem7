### 3. Theory

**1. Linear Regression**

Linear Regression is one of the simplest and most popular supervised machine learning algorithms. It is a statistical technique used for predictive analysis.

- It predicts continuous or numerical values such as house prices, salary, age, sales and temperature.
- It establishes a linear relationship between a dependent variable (Y) and one or more independent variables (X).
- Example: Predicting house prices based on area, number of rooms and location.

**2. Mathematical Representation**

The equation of Linear Regression is:

**Y = a₀ + a₁X + e**

Where:
- Y = Dependent or target variable.
- X = Independent or predictor variable.
- a₀ = Intercept of the line.
- a₁ = Regression coefficient or slope.
- e = Random error.

**3. Working of Linear Regression**

1. Collect the dataset containing independent and dependent variables.
2. Divide the dataset into training and testing data.
3. The algorithm learns the relationship between input and output variables.
4. Calculate the best-fit regression line.
5. Predict numerical values for new inputs.

The best-fit line minimises the sum of squared differences between actual and predicted values.

**4. Types of Linear Regression**

**A. Simple Linear Regression**
- Uses only one independent variable.
- Example: Predicting house price using only the area.
- Equation: Y = a₀ + a₁X

**B. Multiple Linear Regression**
- Uses two or more independent variables.
- Example: Predicting house price using area, rooms, location and age.
- Equation: Y = a₀ + a₁X₁ + a₂X₂ + ... + aₙXₙ

**5. Applications**
1. House price prediction.
2. Sales forecasting.
3. Salary prediction.
4. Business profit prediction.
5. Temperature forecasting.
