### 3. Theory

**1. Support Vector Machine (SVM)**

Support Vector Machine is a supervised machine learning algorithm used for classification and regression problems.

- Its main aim is to find the best decision boundary that separates data points into different classes.
- This decision boundary is called a **Hyperplane**.
- SVM selects the best hyperplane by considering the maximum distance between the boundary and the nearest data points of different classes.
- These nearest data points are called **Support Vectors**.
- Example: SVM can classify emails into two categories:
  1. Spam emails.
  2. Non-spam emails.

**2. Types of SVM**

**A. Linear SVM**
- Used when data can be separated into different classes using a straight line or linear decision boundary.
- Example: Separating two classes using a straight line.

**B. Non-Linear SVM**
- Used when data cannot be separated using a straight line.
- It uses techniques such as the Kernel Trick to create a decision boundary that can separate complex data.

**3. Advantages of SVM**

1. Works well with high-dimensional data.
2. Provides good accuracy for classification problems.
3. Can handle both linear and non-linear data.
4. Works effectively with small and medium-sized datasets.

**4. Disadvantages of SVM**

1. Training can be slow for large datasets.
2. Selecting the correct kernel and parameters can be difficult.
3. It requires proper data preprocessing.
