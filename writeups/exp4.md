### 3. Theory

**1. Multivariate Linear Regression**

Multivariate Linear Regression is a supervised machine learning algorithm used to predict the value of a dependent variable using multiple independent variables.

In simple words, it studies the relationship between multiple input variables and an output variable.

Example: House prices can be predicted using different factors such as:
1. Area of the house.
2. Number of bedrooms.
3. Location.
4. Age of the house.

It helps us understand how different input variables affect the output.

**2. Mathematical Terms**

- Y = Dependent variable.
- X₁, X₂ = Independent variables.
- β₀ = Intercept or constant.
- β₁, β₂ = Coefficients of independent variables.
- ε = Error term.

**3. Characteristics of Multivariate Regression**

1. It studies the relationship between multiple variables.
2. It helps predict output based on multiple input variables.
3. It is used in machine learning, economics, science and medical research.
4. It helps understand how independent variables affect the dependent variable.

**4. Advantages**

1. Finds relationships between multiple variables.
2. Helps identify the effect of independent variables on the dependent variable.
3. Useful for prediction and data analysis.

**5. Disadvantages**

1. Requires mathematical calculations.
2. Can become complex when many variables are used.
3. The output may be difficult to analyse.
4. Results may be affected by errors or outliers.
