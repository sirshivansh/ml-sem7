## 1. Identify the experiment immediately

| Experiment | Topic | Main identification keyword |
|--------|--------|--------|
| Exp 1 | Linear Regression | Best-fit line, numerical prediction |
| Exp 2 | Logistic Regression | Sigmoid, probability, classification |
| Exp 3 | Ensemble Learning | Bagging, Boosting |
| Exp 4 | Multivariate Linear Regression | Multiple input variables |
| Exp 5 | SVM | Hyperplane, Support Vectors |
| Exp 6 | Graph-Based Clustering | K-Means, centroid, clusters |

**Quick memory trick:**

- Exp 1 → Best-fit line
- Exp 2 → Sigmoid
- Exp 3 → Bagging &amp; Boosting
- Exp 4 → Multiple predictors
- Exp 5 → Hyperplane
- Exp 6 → Clustering &amp; Centroid
